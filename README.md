# KomaShift Landing Page

Official landing page for [KomaShift](https://github.com/miftahulmuhaemen/komashift), an effortless desktop comic reader and on-demand context-aware AI translation application for Windows.

## Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Runtime & Package Manager**: [Bun](https://bun.sh/)
- **Styling**: Open Design visual system (Albert Sans, responsive CSS)

## Development

```bash
# Install dependencies
bun install

# Start local dev server
bun run dev

# Build for production (outputs to dist/)
bun run build

# Preview production build
bun run preview
```

## Cloudflare Pages Deployment

- **Framework preset**: Astro
- **Build command**: `bun run build`
- **Build output directory**: `dist`
